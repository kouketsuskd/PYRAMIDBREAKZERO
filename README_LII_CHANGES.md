- HP 700,000 or less now forces the complete internal combat phase to PHASE 5.
- Boss phase display, armor tier, attack duration, speed scaling and boss visuals now follow PHASE 5 at 700,000 HP.
- Added 8 exclusive PHASE 5 attacks (IDs 81-88).
- Existing commands, item counts, music and unlock behavior from DAYBREAK LI are retained.
